# feature-section (pattern)

A marketing section with an editorial heading and a three-column feature grid.

### When to use
- You need to present product features in an editorial multi-column grid.

### Reach for instead
- **stats-band** — when you're presenting numbers, not descriptive feature callouts with icons and body text.
- **pricing** — when the features are tied to specific paid tiers, not the product as a whole.

### Rules
- **Do:** Keep the grid to three (or a multiple of three) features so it reads evenly across the row. **Don't:** Let an uneven feature count leave a dangling, unbalanced last row on wide screens.

### Accessibility
- Each feature's icon is paired with a real heading (<h3>) and body text — the icon alone never carries the feature's meaning.
- Feature headings use a real heading level (<h3>) nested under the section's own <h2>, keeping the outline logical for screen-reader navigation.

### Design tokens
`--muted` · `--primary` · `--muted-foreground`
